# Agents with LangGraph

A flexible framework for building AI agents using **LangChain**, **LangGraph**, and **LangChain‑Groq**. This project provides a set of sub‑agents that can handle documentation, release notes, issue management, and code review tasks, all orchestrated by a central coordinator agent.

## Project Overview

The repository showcases how to combine **LangChain** agents with **LangGraph** workflows to automate common development tasks. The main components are:

- **Documentation Agent** – writes and updates `README.md`, API docs, etc.
- **Release Notes Agent** – generates release notes from PRs, commits, and issues.
- **Issue Agent** – searches, retrieves, and comments on GitHub issues.
- **Code Review Agent** – reviews pull requests and provides feedback.
- **Coordinator Agent** – delegates tasks to the appropriate sub‑agent.

All agents are wired together using LangGraph's state‑machine capabilities, making it easy to extend or replace individual agents.

## Features

- **Modular sub‑agents** for documentation, release notes, issue handling, and code review.
- **LangGraph workflow** that orchestrates agent interactions.
- **Integration with GitHub** via `langchain‑community` utilities.
- **LLM‑backed reasoning** using the powerful `gpt‑oss‑120b` model from Groq.
- Easy to extend with additional tools or custom agents.

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your‑username/agents-with-langgraph.git
   cd agents-with-langgraph
   ```

2. **Create a virtual environment** (recommended)
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # On Windows use `.venv\Scripts\activate`
   ```

3. **Install dependencies**
   ```bash
   pip install -e .
   ```
   The `pyproject.toml` includes all required packages such as `langchain`, `langgraph`, `langchain‑groq`, and `pygithub`.

4. **Set up environment variables**
   Copy the example file and fill in your credentials:
   ```bash
   cp sample.env .env
   # Edit .env and add:
   #   GITHUB_TOKEN=your_github_token
   #   GROQ_API_KEY=your_groq_api_key
   ```

## Usage

The entry point for the workflow is `src/workflow/main.py`.

```bash
python -m src.workflow.main
```

When run, the coordinator agent will listen for a high‑level instruction (e.g., *"Create a documentation and raise a PR for it."*) and delegate the work to the appropriate sub‑agent. The documentation agent will then create or update `README.md`, and the system can be extended to automatically open a pull request.

### Example: Generating Documentation

```python
from src.agents.graph import github_agent

response = github_agent.invoke({
    "messages": [{"role": "user", "content": "Create a documentation and raise a PR for it."}]
})
print(response)
```

The above snippet triggers the documentation workflow defined in `src/agents/graph.py`.

## Configuration

All configurable values are read from environment variables. The most common ones are:

| Variable          | Description                                 |
|-------------------|---------------------------------------------|
| `GITHUB_TOKEN`    | Personal access token for GitHub API access |
| `GROQ_API_KEY`    | API key for Groq LLM services                |
| `OPENAI_API_KEY`  | (Optional) If you switch to an OpenAI model |

You can add additional configuration by extending the `load_dotenv()` call in `src/agents/graph.py`.
